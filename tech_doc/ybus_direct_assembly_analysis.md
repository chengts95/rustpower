# Ybus 直接装配的数理分析：为什么不需要 COO

> 配套设计：`src/new_pf/` 重组第一刀（CSR 行装配 + 预计算偏移槽位）。
> 本文给出"绕开 COO/spgemm 直接装配"的成立条件、构造与复杂度账目。
> 同一论证同时覆盖 Jacobian v4 fill 与 LM KKT 三-fill——它们是同一族方法。

## 1. 通用稀疏装配为什么"必须"经过 COO

通用库（scipy / nalgebra / Eigen）面对的输入是**匿名三元组流** $(i, j, v)$，
库必须自行完成三件事：

1. **pattern 发现**：哪些位置非零，事先未知；
2. **去重**：多个单元可能贡献同一 $(i,j)$，需求和并；
3. **排序**：CSC/CSR 要求列（行）内索引升序。

因此通用装配的下界由排序主导：$O(\mathrm{nnz}\log \mathrm{nnz})$。
COO→CSC 转换器、spgemm 的符号相（counting pass）付的都是这笔钱。
**"不经过 COO 不可能"的信仰，本质是把"通用性税"误当成了物理定律。**

## 2. 我们的前提：pattern 是拓扑的函数，不是数值的函数

电力网络的稀疏结构由**网络拓扑**完全决定，而拓扑是一等公民数据
（支路清单），不需要从数值三元组里重新发现。

**命题 1（pattern 闭性）.**
设拓扑 $T = (\text{母线},\ \{(f_l, t_l)\}_{l=1}^{n_l})$，则

$$
P(T) = \{(i,i)\}_{i=1}^{n_b}\ \cup\ \{(f_l, t_l), (t_l, f_l)\}_{l=1}^{n_l}
$$

每条支路恰好贡献 4 个位置（$Y_{ff}, Y_{ft}, Y_{tf}, Y_{tt}$），
shunt 与负荷只贡献对角元，而对角元恒在。$P$ 与导纳数值无关。∎

**命题 2（槽位可计算性）.**
固定行内邻居升序约定。则：

- 行指针：第 $i$ 行非零数 = $1 + \deg(i)$，一遍度数统计 + 前缀和，
  $O(n_b + n_l)$；
- 行内秩：母线平均度数 $\bar d \approx 3$，逐行局部排序总代价
  $O(\mathrm{nnz}\log \bar d) = O(\mathrm{nnz})$（常数因子极小）。

符号相输出**支路→槽位映射** $\mathrm{slot}[l] = (s_{ff}, s_{ft}, s_{tf}, s_{tt})$，
之后每个非零元的位置都是常数。**每拓扑只做一次。**∎

**命题 3（重复元消解）.**
结构性重复只来自并行线路（同一 $(f,t)$ 的多条支路）。符号相将它们映射到
同一槽位；数值相采用"清零 + 按固定支路序累加"（`vals[slot] +=`），
结果确定且可复现，与 COO 去重和的差异仅为浮点求和顺序。∎

**推论（直接装配定理）.**
符号相每拓扑一次 $O(n_l \log n_l)$ 摊销为零后，
**每次数值装配为 $O(n_l)$：每支路 4–6 次偏移写，零分配、零搜索、零排序。**

## 3. 复杂度账目（PEGASE 9241 尺度）

**初建（拓扑从零建 Ybus）**——这里直接装配独占优势：

| 方案 | 代价 | 说明 |
|---|---|---|
| COO→CSC 转换 | $O(\mathrm{nnz}\log \mathrm{nnz})$ + 分配 | 排序主导 |
| 库 spgemm（$A^\top Y_{prim} A$） | 符号+数值双相 | 实测同规模 spgemm（JᵀJ）为 24 ms/次 量级 |
| **偏移直接装配** | $O(n_l)$，9241 下 ≈ 微秒级 | 符号相已在拓扑建立时付清 |

**增量修改（N-1 跳闸等）**——两家打平，本节不构成分歧：

COO-diff 的 4 元素 patch 减法同样合法：退一条支路只需从 CSC 中
减掉 $Y_{ff}, Y_{ft}, Y_{tf}, Y_{tt}$ 四个贡献，无需全量转换。
patch 带 $(i,j)$ 坐标时每列一次二分查找（$O(\log \deg)$，可忽略）；
patch 带槽位地址时退化为纯写入。两者均不改 pattern，
下游符号链（Jacobian / KKT / 求解器 symbolic）同样全部存活。
**槽位表在此场景的唯一增量价值是把 patch 应用变成 $O(1)$ 纯写，
并充当 patch 的地址载体；不构成否决 COO-diff 的理由。**

真正两家都躲不掉的是 **PV↔PQ 类型切换**：npv/npq 变化会改变
Jacobian 方程结构（未知数扩维、行数变化），pattern 真的变了，
任何数值 patch 都无法糊弄，需要事件队列驱动的结构重分析。
这是事件系统设计里与装配路线选择无关的硬骨头。

## 4. 同族方法

本论证与以下两者是**同一个定理**的三个实例：

1. Ybus 直接装配（本文，`new_pf` 重组目标）；
2. Jacobian v4 fill（`new_dsdvbus4.rs`）：pattern 来自 Ybus，offsets 来自
   `YbusAnalysisCache`（`pq_ends` / `active_ends` / `diag_ptrs`）；
3. LM KKT 三-fill（`src/lm/`）：J / H / Jᵀ / −I 四块共享一个图 pattern，
   全部位置 start-plus-offset。

FEM 中对应技术为 direct stiffness assembly + location array（单元连通表），
六十年代即有；电力系统工具链普遍未采用，原因在于通用库接口不接收拓扑。

## 5. 与时序仿真 / 结构化事件队列的连接

拓扑事件（跳闸、投切）实现为**数值置零、结构常驻**：

- 支路退出 ⇔ 其 4 个槽位贡献置零（或数值相跳过）；
- pattern 不变 ⇒ 下游全部符号产物跨事件存活：
  `YbusAnalysisCache` → Jacobian pattern → KKT pattern →
  KLU / LDL / QDLDL 的符号分解与 AMD 排序；
- 时序仿真的每一帧只付数值相，事件处理不触发任何重分析。

这是"结构化事件队列 + 稀疏直接法"能够共存的技术地基。
