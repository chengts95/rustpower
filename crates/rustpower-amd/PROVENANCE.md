Initial Rust implementation adapted from amd0.2.2, Richard Lincoln/rwl/amd_order, already cached locally. Not a newly authored translation. BSD notices and LICENSE retained. It ports Davis/Amestoy/Duff AMD. This experiment adds a checked/unchecked shared kernel policy,64-bit hash compatibility for SuiteSparse long AMD, and optional Ybus seed initialization matching our C prototype. C comparison is necessary; equivalence is not assumed. The default Rust ordering core retains its original dependency boundary. Optional `klu`/`c_amd` features own the separate KLU adapter and retained C reference. C sources, headers and BSD notices are preserved under `vendor/amd`; active measurement/prototype C resides in `experiments/` with original notices.
